## What is a SnikketX instance?

SnikketX allows anyone to run the open-source SnikketX server software on their
own systems to create a private space for users to connect using the SnikketX
app, and exchange messages, media and calls.

When someone sets up the SnikketX server software, we call it an "instance" of
SnikketX.

Every SnikketX instance has a unique domain name (such as 'snikket.example.com')
and allows creation of user accounts by invitation. For more information,
check out our introduction to the [SnikketX service](https://snikket.org/service/)
software.
