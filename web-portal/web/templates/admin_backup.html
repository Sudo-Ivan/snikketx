Restore checklist

  1. Restore DNS and TLS for the domain, groups. and share. hosts.
  2. Restore Prosody data and the portal secret key before starting services.
  3. Confirm ACME renewal and SRV records on the Certificates page.
  4. Import account packages only into existing accounts that should receive roster and vcard data.
  5. Ask users to re-link push clients after a device wipe.
