# SnikketX Android client

This is the source code for the SnikketX Android client, forked from
[snikket-android](https://github.com/snikket-im/snikket-android) as part of the
snikketx monorepo. It currently tracks Conversations 2.20.2.

SnikketX for Android is based on Snikket, which is based on
[Conversations](https://conversations.im/) by Daniel Gultsch.

The official Conversations repository is available at: https://codeberg.org/iNPUTmice/Conversations

Build with `./gradlew assembleConversationsFreeRelease`. The `conversations`
flavor is the SnikketX build; `quicksy` is inherited from upstream and left
untouched.
